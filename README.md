## Deployment

This project is configured for Netlify. Netlify will run `npm run build` and publish the `dist` folder.

Quick local build:

```bash
npm ci
npm run build
```

To deploy:

- Connect this repository to Netlify and use the default build command `npm run build` and publish directory `dist`.
- Or, after running `npm run build` locally, drag-and-drop the generated `dist` folder into Netlify for a manual deploy.

If you want, I can also set up a Netlify CLI deploy step you can run locally.
